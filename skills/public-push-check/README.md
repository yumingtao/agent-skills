# 公开推送检查

推送到公开远端之前，按固定清单检查即将推送的提交。清单通过只表示这些项过了，不是安全认证。终端里直接执行的 `git push` 不会跑它。行为规则在 [`SKILL.md`](SKILL.md)。作者和提交者只能是仓库允许名单中的人。身份字段里出现代理、机器人或模型就失败。本技能版本是 `1.0.1`。

标记为 `internal`：默认不进入 skills.sh CLI 发现，不发布到 SkillHub、DSH、ClawHub 或 npm。站点列表可能延迟更新。

## 在这套技能里的位置

单独使用时，它对当前仓库即将推送的范围做检查，不依赖本仓库的其他技能。

它不在工程环上。推送到公开远端之前用它。环上的工作结束后要推送时，先过这道清单。

整条环见仓库 README 的[「单独使用，也可以串起来」](../../README.zh-CN.md#alone-or-together)。
