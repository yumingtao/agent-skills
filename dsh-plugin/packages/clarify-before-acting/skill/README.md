# 先澄清再行动

在复杂、模糊或高成本请求上，先把方向问清楚再动手：自己做功课，一次问一个会改变方向的问题，然后交出任务契约。行为规则在 [`SKILL.md`](SKILL.md)。

## 在这套技能里的位置

单独使用时，它把目标、约束、成功标准和上下文问清楚，并写出任务契约。它是这条工程环上的方向闸门。

契约可以交给 [`defect-detective`](../defect-detective/)、[`diagram-generator`](../diagram-generator/) 或 [`workflow-skill-designer`](../workflow-skill-designer/)。这三个技能未安装时，契约仍然成立。

整条环见仓库 README 的[「单独使用，也可以串起来」](../../README.zh-CN.md#alone-or-together)。
