# Skill Maintainer

Edits a skill that already exists. It does not score one. It finds one gap, writes a proposal, and edits only after confirmation. Any directory with `SKILL.md` can be maintained. The behavior rules are in [`SKILL.en.md`](SKILL.en.md). This skill's version is `1.0.6`.

## Where this skill sits

On its own, it maintains the skill you name. It does not require the other skills in this repo.

It is the maintenance station on the engineering loop. A retro log, an evaluation comment, a TRACE pass, or a structure check can hand work to it. A new skill goes to [`workflow-skill-designer`](../workflow-skill-designer/). Logging this session goes to [`session-retrospective`](../session-retrospective/).

The full loop is in the collection README, [Use one, or run them as a loop](../../README.md#alone-or-together).
